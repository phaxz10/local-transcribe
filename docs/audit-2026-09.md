# Performance & durability audit (2026-09-10)

Goal: run acceptably on most recent devices (incl. mid-range phones and Safari) and survive the
things that actually happen in the field: OOM, tab backgrounding, storage eviction, navigation
mid-recording, GPU driver hiccups.

Ranked by impact. Each item names the fix that shipped (or was deferred) in the same pass.

## Must fix (shipped)

1. **Inference runs on the main thread.** Transformers.js pipeline (feature extraction + ORT) is
   created in the page. On WASM devices a 5-minute file freezes the UI for the whole run, mobile
   browsers kill "unresponsive" tabs, and an ORT out-of-memory takes the whole tab (and any
   unsaved recording) with it.
   *Fix:* the pipeline lives in a dedicated module Worker (`src/lib/engine.worker.ts`); the page
   talks to it over a tiny request/event protocol. A worker crash is caught, reported as a job
   error, and the worker is recreated lazily. Cancel = terminate + recreate (immediate).

2. **Peak memory for long files is ~8 bytes per sample.** ffmpeg decoded to f32le, then the
   result was copied again (`new Float32Array(view)`) even though ffmpeg.wasm already transfers the
   buffer. A 2-hour file peaked near 1 GB before inference started.
   *Fix:* decode to s16le (2 bytes/sample), no redundant copy, convert each ≤25 s chunk to
   Float32 right before inference inside the worker. ~4× lower peak.

3. **Live mic re-decoded and re-transcribed the entire recording every 8 s** (O(n²)): the whole
   MediaRecorder blob went through ffmpeg + Whisper from 0:00 each tick. Interim never kept up on
   WASM; on Safari (`audio/mp4`) partial fragments don't decode at all, so interim was dead.
   Switching Workspace tabs unmounted the component and silently stopped the microphone tracks.
   *Fix (phase B):* store-owned Live Session, AudioWorklet PCM tap (16 kHz Int16, no ffmpeg on the
   live path), interim transcribes only the uncommitted tail, recording persisted to IndexedDB in
   5 s chunks as it happens, crash recovery on boot, continue-recording.

4. **Origin storage was never marked persistent.** Chrome/Firefox can evict the whole origin
   (models + transcripts + recordings) under pressure.
   *Fix:* `navigator.storage.persist()` requested after the first successful model download.

5. **Blob URLs leaked.** Every file job / history open created an object URL and never revoked
   the previous one; each pins a File/Blob in memory.
   *Fix:* single setter revokes the prior URL.

## Should fix (shipped)

6. **WebGPU without `shader-f16`** (older Intel iGPUs, some Linux/Mesa): the fp16 weights are
   downloaded, session creation fails, then the WASM weights are downloaded too.
   *Fix:* capability records f16 support; without it the device is treated as WASM up front.

7. **Benchmark ×RT not persisted**, ETA disappeared after every reload. *Fix:* saved in settings.

## Deferred at the time, shipped in the follow-up pass

- **App-shell offline caching.** Models were cached but the PWA shell was not, so an offline launch
  failed. *Fix:* `public/sw.js` replaces the vendored isolation SW and does both jobs — COOP/COEP
  injection plus a build-stamped app-shell precache (network-first navigations, cache-first
  `/assets/*` and `/ffmpeg/*`, HuggingFace untouched).
- **Transcript virtualization** for multi-hour transcripts (ADR-0009 threshold). *Fix:*
  `content-visibility: auto` per Segment row — off-screen rows skip layout and paint while staying
  in the DOM, so Cmd-F and select-all still cover the whole transcript.
- **True download resume** (ADR-0008). *Fix:* `src/lib/download.ts` prefetches each model file with
  an HTTP `Range` request, banks it in IndexedDB every ~8 MB, and seeds `transformers-cache` so the
  pipeline finds it. Cancel now keeps the partial.

## Still deferred

- **`no_repeat_ngram_size: 3`** occasionally eats legitimate repeats ("no, no, no"). Kept: the
  loop-breaker matters more than the rare false positive.
